# Screenshots

These are screenshots of the real site. Each one was taken in headless Chromium from the production build (`npm run build`, then `npm run preview`) after fonts had loaded and animations had settled. No mockups or design files are included. The site is not deployed yet, so no live URL is given here.

Every screenshot except the hero was taken with the browser set to prefer reduced motion. In that mode the site shows its finished state: the whole crimson line is drawn and every section is visible. With normal motion, the line draws as you scroll. The hero was taken with normal motion, after its entrance animation finished.

Viewports are given in CSS pixels. All images use a device pixel ratio of 1, except `mobile-projects.png`, which uses 2.
